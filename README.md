# Python Lessons: Fun & Quick Series

Welcome! This repository is a short, beginner-friendly Python lesson series designed to be fun and quick.

## Lesson Series

1. **Hello, Python!**  
   Print text, use variables, and run your first script.
2. **Decisions & Loops**  
   Learn `if`, `for`, and `while` with mini game-style examples.
3. **Functions in 10 Minutes**  
   Write reusable code with parameters and return values.
4. **Lists, Tuples, and Dictionaries**  
   Store and organize data in practical ways.
5. **String Tricks**  
   Slice, format, and clean text like a pro.
6. **Mini Project: Quiz Game**  
   Combine everything into a small terminal quiz app.

## How to Use This Repo

- Follow lessons in order.
- Keep each lesson short (10–20 minutes).
- Run examples, then try your own twist.

Have fun and keep coding 🚀
